# ClickTrail query-shaped examples

Small, runnable reference implementations for the ClickTrail attribution
handoff layer. Each example shows how observed acquisition context can move from
arrival to a conversion boundary that the host owns. Every example is local-only
and uses synthetic data. No ad-platform or CRM endpoint is called by the tests.

- `nextjs-google-ads-offline-conversions`
- `webhook-to-offline-conversion`
- `twenty-crm-google-ads`
- `chatwoot-lead-attribution`
- `shopify-meta-capi`
