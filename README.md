# ClickTrail query-shaped examples

Small, runnable reference implementations for attribution problems developers search for. Every example is local-only and uses synthetic data. No ad-platform or CRM endpoint is called by the tests.

- `nextjs-google-ads-offline-conversions`
- `webhook-to-offline-conversion`
- `twenty-crm-google-ads`
- `chatwoot-lead-attribution`
- `shopify-meta-capi`
